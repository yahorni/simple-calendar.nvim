INTRODUCTION                                                   *simple-calendar-introduction*

simple-calendar.nvim is a simple calendar plugin for Neovim.

 Features:
- Intuitive navigation using h/j/k/l keys
- Additional Vim-style navigation keys (b/w/e/ge) and arrow keys
- Month switching using p/n keys (and <C-d>/<C-u> alternatives)
- Date selection that opens files based on configurable pattern

==============================================================================
INSTALLATION                                                   *simple-calendar-installation*

Using vim.pack (native packages):
>
    mkdir -p ~/.local/share/nvim/site/pack/plugins/start
    git clone https://github.com/yahorni/simple-calendar.nvim \
        ~/.local/share/nvim/site/pack/plugins/start/simple-calendar.nvim
<
With lazy.nvim, just `{ "yahorni/simple-calendar.nvim" }`.

USAGE                                                             *simple-calendar-usage*

To open the calendar:
>
    :lua require('simple-calendar').open()
<
`open()` shows the date parsed from the current filename when it matches
`daily_path_pattern` (e.g. `2024-10-15.md`), or the week when it matches
`weekly_path_pattern` (e.g. `2025-W03.md`) — focused on today when it's the
current week, otherwise on that week's Thursday; otherwise the current date.
The optional `date` argument is a table with `year`, `month`, `day` fields:
>
    require('simple-calendar').open({ year = 2025, month = 1, day = 15 })
<
Create a keymap for quick access:
>
    vim.keymap.set('n', '<leader>c', require("simple-calendar").open, { desc = "Open [C]alendar" })
<

CONFIGURATION                                               *simple-calendar-configuration*

No configuration required. Optional setup:
>
    require("simple-calendar").setup({
        daily_path_pattern = "",                      -- default: ""
        weekly_path_pattern = "",                     -- default: ""
        show_week_number = false,                     -- default: false
        use_lowercase_paths = false,                  -- default: false
        highlight_unfinished_tasks = false,           -- default: false
        completed_task_markers = { "x", "-" },        -- default: {"x", "-"}
        skip_weekends = false,                        -- default: false
    })
<

Options:

daily_path_pattern~                     (string, default: "")
    strftime pattern for daily note paths. Tokens: %Y, %m, %d, %B, %b, %A,
    %a. Weekday tokens (%a, %A) are validated against the extracted date;
    mismatches cause the file not to be recognized. Directory structures are
    supported (e.g. "notes/%Y/%m-%B/%Y-%m-%d.md"). Must be non-empty for
    journal() and date selection. When set, days with existing notes are bold
    (`CalendarDayWithNote`), missing files dimmed (`Comment`).

weekly_path_pattern~                    (string, default: "")
    strftime pattern for weekly note paths. Supports the daily tokens plus
    %G (ISO week-year), %g (2-digit ISO week-year, 00-49 -> 20xx, 50-99 ->
    19xx) and %V (ISO week number, Monday-first, 01..53). A week is anchored
    at its Monday. Pair %V with %G (e.g. "%G-W%V.md" -> "2025-W03.md"); %V
    with %Y can mismatch across the new-year boundary (Jan 1-3 may belong to
    the previous ISO year). %V without %G/%g, or a pattern with no resolvable
    week tokens at all (neither a %V+%G/%g pair nor %Y/%m/%d), logs a warning
    at setup() and makes weekly("next"/"previous") report the week as
    unresolvable. Must be non-empty for weekly() and the `O` key.

show_week_number~                       (boolean, default: false)
    Show ISO week numbers in a gutter column to the left of each week row,
    with a `W` header label and a `\|` separator. When weekly_path_pattern is
    set, the numbers are styled by the weekly-note existence status (bold
    `CalendarDayWithNote` or dimmed `Comment`).

use_lowercase_paths~                    (boolean, default: false)
    Generate daily and weekly note paths in lowercase (e.g.
    feb-25-2026-wed.md). Default uses os.date() casing (Feb-25-2026-Wed.md).
    File matching is exact.

highlight_unfinished_tasks~             (boolean, default: false)
    Additionally highlight days with unfinished markdown tasks ("- [ ]",
    "* [ ]", "+ [ ]") using the `Todo` group. Days with only completed tasks
    (see completed_task_markers) stay bold like normal note days.

completed_task_markers~                 (table, default: {"x", "-"})
    Single-character markers inside brackets that count a task as completed
    (e.g. "x", "-", "✓", "✅"). Space is not allowed. Matching is exact -
    spaces in brackets are not trimmed. Supports `-`, `*`, `+` list markers.

skip_weekends~                          (boolean, default: false)
    Skip weekends in journal(). E.g. on Friday, journal("tomorrow") opens
    Monday's file; on Monday, journal("yesterday") opens Friday's.

Regardless of the options above, today's day cell is always underlined
(`CalendarToday` highlight group; customize with :hi CalendarToday).

==============================================================================
KEYBINDINGS                                                 *simple-calendar-keybindings*

 When the calendar window is open, the cursor is unified with the selected
 day highlight, always positioned on the right digit of the selected date.

 Key          Action~
 ---          ------
 h            Move left to previous day
 j            Move down to next week
 k            Move up to previous week
 l            Move right to next day
 <Left>       Move left to previous day
 <Right>      Move right to next day
 <Up>         Move up to previous week
 <Down>       Move down to next week
 b, ge        Move left to previous day
 w, e         Move right to next day
 p            Switch to previous month
 n            Switch to next month
 <C-d>        Switch to previous month
 <C-u>        Switch to next month
 o, <CR>      Select current date and open corresponding file
 O            Open the weekly note for the currently selected day's week
 t            Jump to today's date
 q, <Esc>     Close calendar window

JOURNALING & WEEKLY NOTES                                     *simple-calendar-journaling*
                                                              *simple-calendar-weekly*

journal() requires daily_path_pattern; weekly() requires weekly_path_pattern.
Both open the target file, prompting to create it (and parent directories)
when missing.

`journal([arg])` where arg is:
- "today", nil or omitted -> today
- "yesterday" / "tomorrow" -> yesterday / tomorrow
- "next" / "previous" -> the day after / before the currently open daily
  note (requires it to match daily_path_pattern; respects skip_weekends)
- { year = Y, month = M, day = D } -> that date

`weekly([arg])` where arg is:
- "today", nil or omitted -> the week containing today
- "next" / "previous" -> the week after / before the currently open weekly
  note (requires it to match weekly_path_pattern)
- "from_daily" -> the week of the currently open daily note (requires it
  to match daily_path_pattern)
- { year = Y, month = M, day = D } -> that date's week

Other strings display an error. An empty string is treated as "today" (what
:Weekly with no argument passes). If the pattern cannot resolve a week or
the filename contains an invalid ISO week, a specific error is shown.

Usage:
>
    local calendar = require("simple-calendar")
    calendar.journal()                          -- today
    calendar.journal("tomorrow")
    calendar.journal({ year = 2025, month = 1, day = 15 })
    calendar.weekly()                           -- this week
    calendar.weekly("next")
    calendar.weekly("from_daily")
<

Keybinding examples:
>
    vim.keymap.set("n", "<leader>d", calendar.journal, { desc = "open [d]aily note" })
    vim.keymap.set("n", "<leader>t", function() calendar.journal("tomorrow") end,
                   { desc = "open [t]omorrow's daily note" })
    vim.keymap.set("n", "<leader>y", function() calendar.journal("yesterday") end,
                   { desc = "open [y]esterday's daily note" })
    vim.keymap.set("n", "<leader>n", function() calendar.journal("next") end,
                   { desc = "open [n]ext daily note" })
    vim.keymap.set("n", "<leader>p", function() calendar.journal("previous") end,
                   { desc = "open [p]revious daily note" })
    vim.keymap.set("n", "<leader>dw", calendar.weekly, { desc = "open [w]eekly note" })
    vim.keymap.set("n", "<leader>wn", function() calendar.weekly("next") end,
                   { desc = "open [n]ext weekly note" })
    vim.keymap.set("n", "<leader>wp", function() calendar.weekly("previous") end,
                   { desc = "open [p]revious weekly note" })
<

User commands (optional argument accepted):
>
    vim.api.nvim_create_user_command("Journal", calendar.journal, { nargs = "?" })
    vim.api.nvim_create_user_command("Weekly", calendar.weekly, { nargs = "?" })
<
Command line usage with user commands:
>
    nvim -c 'Journal'
    nvim -c 'Journal tomorrow'
    nvim -c 'Weekly'
    nvim -c 'Weekly next'
    nvim -c "lua require('simple-calendar').journal()"
<

Mapping to the user command:
>
    vim.keymap.set("n", "<leader>j", ":Journal<CR>",
                   { noremap = true, silent = true, desc = "Open journal" })
    vim.keymap.set("n", "<leader>jt", ":Journal tomorrow<CR>",
                   { noremap = true, silent = true, desc = "Open tomorrow's journal" })
<

==============================================================================
FUNCTIONS                                                   *simple-calendar-functions*

open([date])~
    Opens the calendar window at the date parsed from the current filename
    (daily or weekly pattern match) or the current date. A weekly match
    focuses today when the note is for the current week, otherwise that
    week's Thursday. See |simple-calendar-usage|.
>
    require("simple-calendar").open()
    require("simple-calendar").open({ year = 2025, month = 1, day = 15 })
<

journal([arg])~
    Opens the daily note for today, yesterday, tomorrow, the next/previous
    day relative to the open note, or a date table. See
    |simple-calendar-journaling|.

weekly([arg])~
    Opens the weekly note for the current week, the next/previous week, the
    open daily note's week, or a date table. See |simple-calendar-journaling|.

setup(config)~
    Configures the plugin with the provided options; all optional. See
    |simple-calendar-configuration|.
